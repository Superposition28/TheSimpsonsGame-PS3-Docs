Registered format coverage

Current output usability and conversion limits, including registered operations and the Godot GRAPH editor importer, compared with the implementation on 2026-10-18. The same colours appear in the Documentation Map. These entries describe code paths, not a fresh end-to-end conversion run.

  • Usable output / source
  • Partial / mixed / needs validation
  • Archive extraction only
  • No registered converter
  • STR → extracted resourcesArchive extraction · Operation 1Container extraction preserves payloads for their own format decoders.
  • TXD → PNGUsable conversion · Operation 3Named images support model textures and bitmap-font atlases.
  • Preinstanced → BLEND / GLB / FBXPartial conversion · Operation 8Geometry import and optional exports; texture/material associations remain partial.
  • GRAPH → TSGNavGraph (.res)Partial import · Godot editor pluginThe enabled TSG Graph Importer reads GUID, nodes and edges for resource use and visualization. Edge boundaries are heuristic; no AStar3D or navigation mesh is generated. This is separate from operations.toml.
  • LH2 → CSVConversion needs validation · Operation 9Column export is registered; binary IDs and text encoding still need validation under the engine Lua host.
  • INF + PNG → FNTUsable conversion · Operation 15Font metrics, glyph rectangles, surviving kerning and atlas references.
  • TOX + LH2 → SRT / VTT / CSVUsable conversion · Operation 16Four output languages; SS supplies labels. Movie companions match by stem and language.
  • SBK → WAVPartial conversion · Operation 10Bank audio is decoded, but exhaustive export of every subsong is not requested.
  • SNU → WAVUsable conversion · Operation 11Stream audio is decoded to Godot-compatible WAV output.
  • MUS → SNR / SNS → WAV segmentsPartial conversion · Operation 12Segments are usable separately; adaptive playback and MSB transition logic are not reconstructed.
  • VP6 → OGVUsable conversion · Operation 13FFmpeg transcodes media; external subtitle generation is separate.
  • Other extracted resource familiesNo registered conversion · No dedicated conversionCharacter, physics, scene, effect and audio-control formats have research notes but no dedicated registered conversion.

Many Xbox 360 and PS3 format variants are not cross-compatible, so Xbox conversion stages are not yet supported. Initialization can set up Xbox source files; downstream extraction and conversion currently target PS3. Shared names, documented byte layouts and PS3 support colours do not establish Xbox support.

Registered format coverage

Xbox 360 support compared with the registered implementation on 2026-10-18. The layout matches the PS3 summary, but statuses apply to Xbox assets. Operation numbers below identify PS3 reference workflows; these entries are not a fresh conversion run.

  • Readable source
  • Partial / mixed / needs validation
  • Archive extraction only
  • Xbox conversion not supported yet / no converter
  • STR → extracted resourcesNot supported yet · PS3 operation 1 is the referenceRecorded Xbox extraction inventories are research evidence; they do not establish support in the registered extraction stage.
  • ITXD → PNGNot supported yet · No registered ITXD decoderXbox Xenos texture layout differs from PS3 TXD. Operation 3 does not provide ITXD conversion.
  • XEN preinstanced → BLEND / GLB / FBXNot supported yet · PS3 operation 8 is the referenceXbox .dff.XEN.preinstanced and .rws.XEN.preinstanced assets cannot inherit PS3 geometry or material support.
  • GRAPH → TSGNavGraph (.res)Xbox support unvalidated · Godot editor pluginThe PS3 GRAPH importer is a format reference; Xbox binary compatibility and resource output are not established.
  • LH2 → CSVNot supported yet · PS3 operation 9 is the referenceThe Xbox NTSC inventory includes base, English and StringIDs tables. PS3 localization export status does not validate these variants.
  • INF + texture atlas → FNTNot supported yet · PS3 operation 15 is the referenceThe PS3 font workflow depends on decoded atlas images; the Xbox ITXD texture stage has no registered decoder.
  • TOX.XEN + LH2 → SRT / VTT / CSVNot supported yet · PS3 operation 16 is the referenceThe .XEN subtitle timing variant needs platform-specific validation; PS3 subtitle output does not establish Xbox conversion support.
  • SBK → WAVNot supported yet · PS3 operation 10 is the referenceThe shared sound-bank name does not establish compatible Xbox payloads or complete subsong decoding.
  • SNU → WAVNot supported yet · PS3 operation 11 is the referenceXbox stream audio is inventoried, but the registered PS3 workflow does not establish Xbox codec and payload support.
  • MUS → SNR / SNS → WAV segmentsNot supported yet · PS3 operation 12 is the referenceThe PS3 segment workflow does not establish Xbox music decoding; adaptive playback also remains separate.
  • VP6 → OGVNot supported yet in the Xbox pipeline · PS3 operation 13 is the referenceA shared media format does not establish support for Xbox extraction, source paths and companion resources in the registered workflow.
  • Lua and text → readable sourceReadable source · No binary conversion neededShared Lua comparisons and root locale notes cover Xbox variants; the original game runtime is not reconstructed.
  • Other extracted resource familiesNo registered Xbox conversionXEN resources and shared character, physics, scene, effect and audio-control families remain research references.
