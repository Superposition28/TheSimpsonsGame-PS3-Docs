Pipeline Format Coverage

Current extraction and conversion support from the registered operations and Lua/BMS pipeline. This reflects working code paths, not the completeness of reverse-engineering notes.

  • Green Usable output
  • Yellow Partial conversion
  • Blue Analysis only
  • Orange Legacy md analysis
  • Grey No current support
  • .strContainer extractionQuickBMS extracts embedded resources; the archive itself is not converted.
  • .txd -> .pngUsable outputTexture dictionaries are extracted to PNG files.
  • .dff.PS3.preinstanced, .rws.PS3.preinstanced -> .blend, .glb/.fbxPartial conversionGeometry exports; material and texture assignment remain incomplete.
  • .LH2, .en.LH2, .es.LH2, .fr.LH2, .it.LH2, .ss.LH2 -> .csvUsable outputLocalization tables export to CSV.
  • .exa.snu -> .wavUsable outputVoice and stream audio converts through vgmstream.
  • .mus -> .wavUsable outputQuickBMS extracts temporary .snr/.sns pairs, then vgmstream decodes WAV segments.
  • .vp6 -> .ogvUsable outputVideos convert through the registered ffmpeg operation.
  • .graphPartial conversionImported manually through the independent Godot graph importer.
  • .bin, .lua, .hud.bin, .txt, .alb, .amb, .bsp, .ctb, .hkt.PS3, .hko.PS3, .acs.PS3, .bbn.PS3, .bnk.PS3, .rcb.PS3, .shk.PS3, .tox.PS3, .xml.PS3, .rcm_b, .sbk, .smb, .toc (.occ.toc), .uix, .vfbLegacy Markdown analysisAnalysis exists only in the old embedded-format Markdown notes; no extraction or conversion operation is registered.
  • .dat, .meta.xml, .lighttoc, .cec.ps3, .shk, .infAnalysis onlyFormat notes exist, but no extraction or conversion operation is registered.
  • .imb, .mib, .msb, .aub, extensionlessNo current supportNo usable extraction or conversion route or format analysis is currently available.
