Pipeline Format Coverage

Current extraction and conversion support from the registered operations and Lua/BMS pipeline. This reflects working code paths, not the completeness of reverse-engineering notes.

  • Green Usable output
  • Yellow Partial conversion
  • Blue Analysis only
  • Orange todo
  • Grey No current support
  • .str Container extraction QuickBMS extracts embedded resources; the archive itself is not converted.
  • .txd -> .png Usable output Texture dictionaries are extracted to PNG files.
  • .dff.PS3.preinstanced, .rws.PS3.preinstanced -> .blend, .glb/.fbx Partial conversion Geometry exports; material and texture assignment remain incomplete.
  • .LH2, .en.LH2, .es.LH2, .fr.LH2, .it.LH2, .ss.LH2 -> .csv Usable output Localization tables export to CSV.
  • .exa.snu -> .wav Usable output Voice and stream audio converts through vgmstream.
  • .mus -> .wav Usable output QuickBMS extracts temporary .snr/.sns pairs, then vgmstream decodes WAV segments.
  • .vp6 -> .ogv Usable output Videos convert through the registered ffmpeg operation.
  • .graph imported into godot via extension importable into godot or blender, not fully usable yet
  • .dat Structural outline Header and entity fields are documented, but entity sizing and attribute decoding remain incomplete. No extraction or conversion operation is registered.
  • .meta.xml Detailed structural map Header, section offsets and counts, relative strings, attribute records, and value-type flags are documented. No extraction or conversion operation is registered.
  • .cec.ps3 Partial record layout The fixed header and event-entry fields are documented, but input-pattern structures remain unspecified. No extraction or conversion operation is registered.
  • .shk Documented command layout The haptic header and fixed-size command entries are documented, but no extraction or conversion operation is registered.
  • .inf Near-complete parsing specification The signature, big-endian header, glyph and kerning tables, and .fnt export procedure are documented; no operation is registered.
  • .imb full hex dump and shallow ai analysis ...
  • extensionless full hex dump and shallow ai analysis two files, LightTOC and StreamSetConfig
  • .mib full hex dump and shallow ai analysis ...
  • .msb full hex dump and shallow ai analysis ...
  • .smb Format Analysis An index and metadata table for EA's streaming audio engine dictating how external .exa sound streams load and play[cite: 1].
  • .tox.PS3, full hex dump and shallow ai analysis ...
  • .uix, full hex dump and shallow ai analysis ...
  • .sbk, full hex dump and shallow ai analysis ...
  • .bin, .lua, .hud.bin, .txt, .alb, .aub, .amb, .bsp, .ctb, .hkt.PS3, .hko.PS3, .acs.PS3, .bbn.PS3, .bnk.PS3, .rcb.PS3, .shk.PS3, .xml.PS3, .rcm_b, .toc (.occ.toc), .vfb incomplete or todo
