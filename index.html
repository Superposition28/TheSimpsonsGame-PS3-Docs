PS3: Pipeline Format Coverage

Format understanding and practical support at a glance. This homepage combines research progress with Remake Engine implementation progress; each entry states its limits.

41 tracked format references · 11 usable / readable; 9 partial; 19 analysis only; 2 research TODO; 0 unverified.

  • Green Usable output / readable source
  • Yellow Partial implementation / needs validation
  • Blue Analysis only
  • Orange Research TODO / inventory only
  • Grey No verified platform support

Language variants and equivalent model suffixes are grouped. Counts describe the entries below, not a percentage of all game data understood. Green does not mean every field or original runtime behavior is recovered. Evidence last reviewed 2026-10-31.

  • .STR Container extraction · Operation 1Container extraction preserves payloads for their own format decoders.
  • .txd Usable conversion · Operation 5Named images support model textures and bitmap-font atlases.
  • .preinstanced Partial conversion · Operation 7Geometry import and optional exports via operation 7; RenderWare clump hierarchy, EARS_MESH structure and rwID_MATERIAL texture mapping are documented. Remake material pipeline assignment remains partial.
  • .lh2 Validated text and dialogue lookupAll 654 original EU tables are readable; language/label columns and 7,314 dialogue links are validated. Reserved header fields and original subtitle timing remain unresolved. Operation 8 Lua CSV fidelity is a separate validation gap.
  • .EXA.SNU Usable conversion · Operation 12Stream audio is decoded to Godot-compatible WAV output.
  • .MUS Partial conversion · Operation 13Segments are usable separately via operation 13; 1-to-1 joins to MSB checksums and SNS stream offsets are documented, but adaptive playback and transition logic are not reconstructed.
  • .VP6 Usable conversion · Operation 14FFmpeg transcodes media; external subtitle generation is separate.
  • .graph Partial import · Godot editor pluginThe enabled TSG Graph Importer reads GUID, nodes and edges for resource use and visualization. Edge boundaries are heuristic; no AStar3D or navigation mesh is generated. This is separate from operations.toml.
  • .inf Usable conversion · Operation 9Font metrics, glyph rectangles, surviving kerning and atlas references.
  • .tox.PS3 Usable conversion · Operation 10Four output languages; SS supplies labels. Movie companions match by stem and language.
  • .sbk Partial conversion · Operation 11Bank audio is decoded, but exhaustive export of every subsong is not requested.
  • .BIN ELF64 layout and runtime analyzedELF64 layout, TOC architecture, PRX imports, embedded SPU workloads, Cell GCM RSX graphics pipeline and 149 actor registrations documented from EBOOT.elf disassembly. No runtime loader or executable translation is registered.
  • .LUA Readable source / checked layoutOriginal Lua source is readable. The game API and original runtime behavior are not thereby implemented by a remake.
  • .acs.PS3 Partial import · Godot collisionTest264 collision-directory files (and all 267 canonical ACS files) walked to EOF; Godot collisionTest builds unresolved capsule/box/sphere preview galleries and joins BBN aliases and visual HAnim nodes. Shape semantics and pose/coordinate reconstruction remain partial; separate from operations.toml.
  • .alb Validated records and dialogue linksOriginal EU version-6 records are 24 bytes; all 14,283 distinct-payload records join to SMB streams and LH2 text. Standalone subtitle videos are usable. Alias semantics, stream-slot roles and event triggering remain unresolved.
  • .amb Analysis onlyThe name expansion and precise runtime role remain tentative. Audio and interaction contexts must be distinguished per sample; neither a universal AMB schema nor an event resolver is implemented in the operation pipeline.
  • .aub Research TODO / inventory onlyInventory and research scope only; the prior ALB/CTB description was not an AUB byte-layout specification.
  • .bbn.PS3 Partial lookup · Godot collisionTest33-byte header, 52-byte records and SDBM bone-name hashes validated on player_default.bbn.PS3; Godot collisionTest resolves ACS node aliases against HAnim bones. Full animation/IK and runtime semantics remain partial; separate from operations.toml.
  • .bnk.PS3 Analysis onlyClip compression, transitions and bindings are not completely decoded. This animation-bank suffix is distinct from the .sbk audio-bank suffix; operation 7 does not decode BNK animation.
  • .bsp Analysis onlyNode/lump semantics and collision/visibility uses remain partly inferred. This is not a specification for an unrelated BSP family, and operation 7 does not import these files.
  • .cec.ps3 Analysis onlyNo dedicated controller-event converter is registered. A contextual relationship with character animation does not establish event-to-clip IDs.
  • .ctb Analysis onlyControl-flow interpretations are tentative. Shared names/IDs do not establish every field or a complete playback graph. No CTB decoder is registered.
  • .hko.PS3 Partial import · Godot collisionTest25 collision-directory files are identical copies of one packfile containing 13 boxes and 3 spheres; Godot collisionTest builds BoxShape3D and SphereShape3D previews. Non-collision-directory HKO contents and runtime transforms remain unresolved; separate from operations.toml.
  • .hkt.PS3 Partial import · Godot collisionTest112 collision-directory HKT files audited and imported in Godot collisionTest as ConcavePolygonShape3D / BoxShape3D static bodies with visual GLB pairing, raycast and physics checks. Non-collision-directory HKT variants and runtime world placement remain partial; separate from operations.toml.
  • .imb Analysis onlyMaterial-interaction and effect-cluster roles are inferred from layout and context. No MurmurHash/Jenkins identification or numeric join to sound/VFX resources is demonstrated.
  • .meta.xml Analysis onlySection layouts are documented, but complete runtime object reconstruction and cross-resource resolution are not registered operations.
  • .mib Analysis onlyBus IDs, parameter meanings, variable record lengths and hash algorithms are not fully verified. The parser sketch below is illustrative, not a registered Deno or Lua operation.
  • .msb Pathfinder map and MUS joins analyzedOuter 80-byte wrapper header, PFDx map at offset 0x50 with 9 sections, and plaintext symbol trailer documented across all 19 files. 1-to-1 joins to MUS checksums and SNS stream offsets and EBOOT.elf Pathfinder calls are verified; transition logic is not implemented by operation 13.
  • Extensionless: LightTOC / StreamSetConfig Analysis onlyHex dumps establish observed bytes only. Do not assign a schema, decoder or role solely because a file has no extension.
  • .rcb.PS3 Research TODO / inventory onlyPaths and size variation are recorded. Controller logic, resource bindings and animation joins remain unresolved.
  • .rcm_b Analysis onlyDirectory context supports an audio association. No verified mapping from these records to SBK, SMB or SNU events is available.
  • .shk Analysis onlyCommand semantics and target-object resolution are incomplete. No Shock interpreter is registered.
  • .dat.simgroup / .dat.uie Analysis onlyExtraction categorizes identified SimGroup/UIE data and leaves unidentified families as .dat. Record bytes are preserved; entity joins and runtime scene assembly remain unresolved.
  • .smb Stream lookup usable; playback metadata partialAll 99 original EU banks have validated 96-byte records naming all 7,413 distinct SNU files. Bank/stream joins support dialogue lookup; flags, attenuation fields and other playback semantics remain partly unknown.
  • .toc Analysis onlyThe two documented families must be identified separately. Offset targets and visibility-volume meanings remain partly inferred; TOC is not the STR section descriptor table itself.
  • .txt Analysis onlyThe observed locale table is one text use case, not a schema for all .txt files. No general text conversion is registered.
  • .uix Analysis onlyAPT and ActionScript-like strings are observed. They do not prove Scaleform middleware, a complete Flash runtime or an executable UI reconstruction. Font names can suggest associations but need explicit resource matching.
  • .vfb Analysis onlyField names such as duration, intensity and fade are provisional until runtime correlation. No effect player or VFB converter is registered.
  • .xml.PS3 Analysis onlyThe overall schema, timing semantics and cross-asset joins remain hypotheses. A shared .xml substring does not imply the MetaModel binary layout.
  • .TXT Readable source / checked layoutAll five supplied PS3/Xbox locale tables were compared; headers, ASCII records and regional differences are documented.
  • PARAM.SFO Readable source / checked layoutEU, US and demo metadata and binary layouts are documented. Metadata identity does not fingerprint the complete game build.
