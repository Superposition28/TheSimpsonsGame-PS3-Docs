Registered format coverage

Current output usability and conversion limits, including registered operations and the Godot GRAPH editor importer, compared with the implementation on 2026-10-18. The same colours appear in the Documentation Map. These entries describe code paths, not a fresh end-to-end conversion run.

  • Usable output / source
  • Partial / mixed / needs validation
  • Archive extraction only
  • No registered converter
  • STR → extracted resourcesArchive extraction · Operation 1Container extraction preserves payloads for their own format decoders.
  • TXD → PNGUsable conversion · Operation 3Named images support model textures and bitmap-font atlases.
  • Preinstanced → BLEND / GLB / FBXPartial conversion · Operation 8Geometry import and optional exports; texture/material associations remain partial.
  • GRAPH → TSGNavGraph (.res)Partial import · Godot editor plugin The enabled TSG Graph Importer reads GUID, nodes and edges for resource use and visualization. Edge boundaries are heuristic; no AStar3D or navigation mesh is generated. This is separate from operations.toml.
  • LH2 → CSVConversion needs validation · Operation 9Column export is registered; binary IDs and text encoding still need validation under the engine Lua host.
  • INF + PNG → FNTUsable conversion · Operation 15Font metrics, glyph rectangles, surviving kerning and atlas references.
  • TOX + LH2 → SRT / VTT / CSVUsable conversion · Operation 16Four output languages; SS supplies labels. Movie companions match by stem and language.
  • SBK → WAVPartial conversion · Operation 10Bank audio is decoded, but exhaustive export of every subsong is not requested.
  • SNU → WAVUsable conversion · Operation 11Stream audio is decoded to Godot-compatible WAV output.
  • MUS → SNR / SNS → WAV segmentsPartial conversion · Operation 12Segments are usable separately; adaptive playback and MSB transition logic are not reconstructed.
  • VP6 → OGVUsable conversion · Operation 13FFmpeg transcodes media; external subtitle generation is separate.
  • Other extracted resource familiesNo registered conversion · No dedicated conversionCharacter, physics, scene, effect and audio-control formats have research notes but no dedicated registered conversion.
