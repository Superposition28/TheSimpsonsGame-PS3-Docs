Ownership and consumers

naming.json owns this documentation snapshot. An attributed historical notes snapshot preserves the original observations and uncertain associations. Original notes remain in the parent checkout at reversing/data/naming.md; executable rename rules remain in config/RenameMap.db. Changes to those sources need an explicit reconciliation, not an automatic overwrite of research conclusions.

AudioMap.yaml is the maintained V2 audio registry at its established path, with a JSON Schema. Its game associations are documented separately from the Remake Engine consumer contract.

Use source and path conventions for actual file references. Regenerate this page with python tools/render_reference.py.
