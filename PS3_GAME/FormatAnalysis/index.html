File format analysis

This tree follows format origin: source-level formats first, then resources extracted from containers such as STR. The counts below are recorded reference inventories, supplemented by the 2026-10-28 original EU ALB/LH2/SMB audit; they are not a fresh scan of every region; grouped totals include their indented child rows and must not be added to them.

How the files fit together

  • Media and localization: VP6/OGV supplies playback, TOX supplies cue times, LH2 supplies text, and INF plus TXD supplies bitmap-font data for a renderer.
  • Audio and music: SNU and SBK carry decodable sounds. ALB bank/stream and StringID joins connect 7,314 individual dialogue streams through SMB to LH2 text; CTB event logic and SMB/MIB playback metadata remain partly understood. MSB names MUS containers whose SNR/SNS segments are decoded separately.
  • World and characters: preinstanced geometry uses texture dictionaries. Animation, collision, navigation, object properties and VFX live in separate resources with different levels of research coverage.

.PS3 and .XEN are platform suffixes. A shared word such as bank, table, graph or XML does not establish a common binary layout. Unknown descriptions below are explicitly marked; use each format's evidence section before implementing a parser.

Inventory scope: PS3 EU is the baseline. Historical source and extracted counts below have not been rescanned during this migration; Xbox inventories retain their stated platform scope. Extracted Full and FullFlattened paths are separate namespaces. See reference sources.

Entry point for file format notes and reverse-engineering writeups. PARAM.SFO platform metadata is documented at its PS3_GAME root location, separately from the USRDIR and extracted-resource counts below.
