Game format research · Xbox 360 executable specification

XEX2 container & header descriptors

The Xbox 360 executable container begins with a 24-byte header followed by an array of 8-byte optional header descriptors (key/value or key/offset pairs):

XEX2 Header (24 bytes)
Offset Type Field Observed value
0x00 uint32 BE Magic 0x58455832 ("XEX2")
0x04 uint32 BE Module Flags 0x00000001 (Title Module)
0x08 uint32 BE PE Data Offset 0x00003000
0x0C uint32 BE Reserved 0x00000000
0x10 uint32 BE Certificate Offset 0x00000098
0x14 uint32 BE Optional Header Count 16

Decrypted PE basefile layout

Decompressing and decrypting default.xex with XexTool (XexTool -b default.exe default.xex) yields a 15,466,496-byte uncompressed PowerPC PE image loaded at 0x82000000. Section boundaries from the image descriptor and generated IDC script:

Kernel and XAM imports

Unlike the PS3 version's PRX module tables, Xbox 360 binaries import system functions through ordinal import tables resolved by the kernel loader:

  • xam.xex (v2.0.5766.0): Xbox Application Model, handling game voice, notifications, gamer profiles, achievements, and input controller reading.
  • xboxkrnl.exe (v2.0.5766.0): Core operating system kernel providing thread scheduling, virtual memory management, synchronization events, and D3D ring buffer submission.

Cross-architecture correspondence to PS3 EBOOT

Because both Xbox 360 Xenon and PS3 Cell PPE execute Big-Endian 64-bit PowerPC code with 32-bit pointers, the game logic, RenderWare engine subsystems, and asset schemas correspond 1:1 between default.xex and EBOOT.BIN:

Tools and integrations

Optional Remake Engine implementation notes describe project-specific support and limitations. They are separate from the format specification and original-game behavior.

Support for Xbox 360 binary inspection and execution is provided across multiple tools in this workspace:

  • Source/XBOX360/XexTool-windows-x64/XexTool.exe: Reads XEX headers (-l), strips encryption/compression, and dumps the raw PE basefile (-b) and IDA IDC scripts (-i).
  • reversing/boot/: Native C# bootloader featuring XexFile.cs, auto-discovering and verifying Xbox 360 game trees alongside PS3.
  • Source/XBOX360/GamePCport/ (TheSimpsonsGameRecomp): Static binary recompiler translating Xbox 360 Xenon PPC code to native x86-64 C++ with Direct3D 12 and Vulkan rendering on Windows, containing 1,077 mapped function boundaries in functions_patch.toml and 73 D3D dispatch handlers in d3d_method_table.md.
  • operations/init: Module initialization script automatically parsing default.xex to identify Xbox 360 title/media variants.

Evidence and limitations

Header bytes, optional descriptors, execution IDs, and segment layouts were directly verified against both Source/XBOX360/EU/1/TSG/default.xex and Source/XBOX360/US/1/extractedFiles/default.xex using XexTool.exe and custom binary inspection tools on 2026-10-31.

Direct function correspondences were confirmed by cross-referencing disassembled PowerPC instruction sequences and string references against the PS3 static flow index. Dynamic runtime behavior notes are corroborated by the native PC port's verified execution.
