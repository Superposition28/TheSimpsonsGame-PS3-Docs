Related files and formats

The executable shares a source-disc tree with STR archives, movies, audio and localization resources. That context is not evidence of a decoded executable-to-resource reference. The format relationship guide describes asset workflows independently of EBOOT internals.

Operation support

No executable decoder, converter or reconstruction is registered in operations.toml. STR extraction, media conversion and normalization do not convert this executable. Operation 14 writes a separate launch manifest for the prebuilt Godot project; it does not translate EBOOT.BIN. See the operation pipeline.

Evidence and limitations

Size and SHA-256 were computed from the supplied file, the opening 32 bytes were inspected, and the listed PARAM.SFO fields were read on 2026-10-18. No trusted retail digest was compared and no cryptographic authenticity check was performed.

Executable internals, functions, dependencies, embedded assets, protection details and runtime behavior remain uninvestigated. This is intentionally a basic reference entry, not a reverse-engineered executable specification.
