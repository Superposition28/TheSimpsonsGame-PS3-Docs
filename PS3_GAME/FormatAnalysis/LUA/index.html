Operation support

No dedicated decoder or conversion for this suffix is registered in operations.toml. For an STR payload, operation 1 extracts bytes and operation 6 can normalize its path; those steps do not interpret the resource. External viewers, research pseudocode and optional engine/editor extensions are separate from registered operation coverage.

Pipeline reference records the exact inputs, outputs and limitations. Dependencies in the manifest do not automatically prove that every practical input has been produced.

Evidence and limitations

The script inventory and historical hashes do not establish that the original game API is implemented by Remake Engine. No source-Lua translation operation is registered.

Operation coverage is grounded in the module manifest and its referenced implementations. Detailed field tables and retained samples below/above are the existing research evidence; labels such as tentative, observed and context must not be read as a complete runtime implementation. Offsets in the added tables are zero-based; range ends are exclusive unless stated otherwise.

The EU PS3 and Xbox 360 NTSC source trees contain the same three Lua files. Their SHA-256 hashes match pairwise, so no content differences were found in these scripts.

Paths below refer to local source copies, which are not distributed with this documentation site. The recorded hashes describe the original comparison, not a new cross-platform verification.

simpsons_gameflow.lua

Builds the game's flow configuration: registers costumes, creates the game and episodes, and attaches modes, maps, movies, and metric screens.

  • PS3 EU: EU/PS3_GAME/USRDIR/simpsons_gameflow.lua
  • Xbox 360 NTSC: x360-NTSC/x360-NTSC/simpsons_gameflow.lua

simpsons_gameflow_helpers.lua

Provides constructors for game, episode, mode, movie, map, and metric-screen packages. The helpers attach created objects to the game-flow hierarchy and transfer ownership to Lua.
