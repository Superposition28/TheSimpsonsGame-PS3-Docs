Documentation/Format index

Relationships between game formats

An asset usually spans several files: one stores data, another names or times it, and another describes how it is used. The connections below distinguish implemented joins, observed names and contextual relationships. Each format page gives the detailed layout and the limits of its evidence.

Movies, localized text and fonts

STR archive ──extract──> TOX timing + LH2 localization + INF font data + TXD textures
source movies ──copy──> VP6 ──operation 13──> OGV
TOX StringID + LH2 StringID ──operation 16──> SRT / VTT / multilingual CSV
INF + TXD-derived PNG ──operation 15──> FNT + atlas reference
movie clock + timed text + a renderer/font ──> displayed subtitles

FMV subtitle timing (.tox.PS3) supplies StringID, start time, duration and flags. Localization table (.LH2) supplies text keyed by the same ID. Movie container (.vp6) supplies the movie timeline and media streams. Bitmap font descriptor (.inf) supplies glyph metrics and atlas coordinates; Texture dictionary (.txd) supplies the atlas pixels. Font resources are a rendering connection: no direct font pointer in TOX, LH2 or VP6 has been demonstrated.

Operation 16 matches cleaned movie/timing stems and the movie's language directory. It joins numeric TOX/LH2 IDs, rather than guessing text from filenames. The observed global EN/ES/FR/IT tables provide translations; SS provides internal labels. Operation 9 exports LH2 independently. Subtitle generation does not require a font conversion, and video conversion does not generate or burn in captions.

Dialogue, sound banks and mix metadata

Streamed audio (.exa.snu) contains streamed audio; Sound bank (.sbk) can contain multiple embedded subsongs. Operations 11 and 10 decode those input families separately. The common EA audio concepts do not establish that an SBK must refer to an external SNU.

Audio alias/library metadata (.alb) and Audio control metadata (.ctb) have paired names and repeated identifiers in samples, supporting alias/event metadata roles. Stream metadata (.smb) contains external .exa stream names. These observations are useful leads, but a full event-to-stream resolver, numeric ID mapping and every playback condition remain unimplemented. Mix metadata (.mib) and Character audio metadata (.rcm_b) add mix/character-audio context; their exact joins are unresolved. AMB resource (.amb) and AUB resource (.aub) must be identified from their own bytes rather than treated as ALB variants.

The audio directory page describes the maintained AudioMap registry used for organization. AudioMap rename rules are pipeline metadata; they are not evidence of the binary ALB/CTB hash algorithm or a substitute for original audio-engine logic.

Interactive music

Interactive music metadata (.msb) samples name a MUS container and expose Pathfinder event/part symbols. MUS holds descriptors for paired SNR metadata and SNS payloads. The registered BMS reads descriptors at 0x28, scales the SNR offset by 0x10 and SNS offset by 0x80, then extracts each pair. Operation 12 decodes segment WAVs. It does not evaluate the MSB state machine or reconstruct a complete adaptive score.

Rendered assets, scenes and effects

Preinstanced models geometry references texture names that the Blender workflow associates with TXD-derived PNGs. Texture lookup depends on normalized path/map context and remains partial. Compiled MetaModel (.meta.xml) properties and Simulation group (.dat) instances provide additional object/scene concepts; operation 8 does not assemble those around the mesh.

Impact resource (.imb) contains candidate material/effect clusters; Effect bundle (.vfb) contains named effect blocks and timing-like parameters. An impact-to-effect/audio join is plausible but the hash algorithms and target IDs are unresolved. Decoding geometry or a sound stream does not reconstruct an effect player.

Character motion and collision

Bone bindings (.bbn.PS3) joint names, Animation bank (.bnk.PS3) animation/state names, Controller event configuration (.cec.ps3) events and Character/controller resource (.rcb.PS3) CCT-export resources describe complementary character-system data. Exact numeric joins and compressed animation decoding are not established. These animation banks are distinct from SBK audio banks.

Havok collision resource (.hkt.PS3) and Havok object resource (.hko.PS3) carry Havok-associated physics data in the observed trees; Character collision resource (.acs.PS3) occurs in character collision directories. Shared asset paths suggest associations with visual meshes and bone bindings. They do not prove a shared record format or universal static/animated distinction.

World organization, sequences and interface

Spatial partition resource (.bsp) spatial structures, Navigation graph (.graph) navigation nodes and Table-of-contents resources (.toc) streaming/occlusion indexes describe related level space with different data models. No shared node numbering or automatic coordinate transform is established. The octc/occl TOC family must be separated from generic stream TOCs and STR's own section directory.

Compiled sequence resource (.xml.PS3) has observed seqm/seqb blocks, whereas binary MetaModel data uses a different layout despite its .meta.xml name. Shock resource (.shk.PS3) command records may belong to sequencing logic, but no common opcode mapping is demonstrated. Compiled APT interface (.uix) contains APT and UI resource/font-name strings; full module-to-font/texture resolution and UI execution remain separate work.

Shared data conventions and common traps

Conventions to preserve when following a reference
DataHow to interpret it
32-bit IDs / hashesJoin only within a verified namespace. Lowercase SDBM is validated for the documented TOX dialogue labels; it is not a proven universal algorithm for material, bone, audio and object identifiers.
OffsetsRecord whether a value is file-absolute, section-relative, mesh-relative or scaled. LH2 pointers are absolute; MUS SNR/SNS offsets have different units. Never infer a pointer base from the integer width.
Text and glyph codesLH2 text uses observed Windows-1252 bytes; INF has custom character remaps and controller glyph aliases. Decoding text and selecting glyphs are separate operations.
Byte order / floatsPS3 files are not uniformly big-endian. RenderWare framing, native texture fields and preinstanced model fields can differ. Preserve unknown words rather than assigning meanings from familiar float values alone.
Timing / coordinatesTOX start/duration values are milliseconds. INF texture coordinates are 12.4 fixed-point pixels. VFX timing and world transforms need their own validation; do not transfer units between formats.
Compound suffix / path UIDUse the complete suffix to distinguish .bnk.PS3, .tox.PS3 and .dff.PS3.preinstanced. A normalized six-hex filename suffix identifies path context; it is not automatically an embedded StringID.

See the operation reference for source links and exact registration. Cross-platform concepts can overlap while native layouts differ; compare Xbox ITXD with PS3 TXD before sharing a decoder.
