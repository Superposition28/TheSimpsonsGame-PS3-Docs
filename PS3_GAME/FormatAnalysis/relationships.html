Documentation/Format index

Relationships between game formats

An asset usually spans several files: one stores data, another names or times it, and another describes how it is used. The connections below distinguish implemented joins, observed names and contextual relationships. Each format page gives the detailed layout and the limits of its evidence.

Source scope: PS3 EU is the baseline. Each relationship must retain its observed, inferred or implementation-derived status. Source and path conventions apply to examples; contextual association is not a verified runtime dependency.

Movies, localized text and fonts

STR archive ──contains──> TOX timing + LH2 localization + INF font data + TXD textures
VP6 movie ──supplies──> media timeline
TOX StringID ──joins by ID──> LH2 localized text / internal labels
INF glyph metrics ──associate with──> TXD atlas pixels
movie clock + timed text + glyph rendering ──> subtitle presentation

FMV subtitle timing (.tox.PS3) supplies StringID, start time, duration and flags. Localization table (.LH2) supplies text keyed by the same ID. Movie container (.vp6) supplies the movie timeline and media streams. Bitmap font descriptor (.inf) supplies glyph metrics and atlas coordinates; Texture dictionary (.txd) supplies the atlas pixels. Font resources are a rendering connection: no direct font pointer in TOX, LH2 or VP6 has been demonstrated.

TOX and LH2 join by numeric StringID. Observed global EN/ES/FR/IT tables provide translated text; SS provides internal labels. Movie-stem associations are useful evidence but do not establish the original runtime lookup algorithm. Subtitle timing, text resolution, font rendering and media playback are separate responsibilities.

Dialogue, sound banks and mix metadata

Streamed audio (.exa.snu) contains streamed audio; Sound bank (.sbk) can contain multiple embedded subsongs. These input families must be identified and interpreted separately. The common EA audio concepts do not establish that an SBK must refer to an external SNU.

Audio alias records (.alb) supplies a bank/stream pair joining to SMB external .exa filenames, and a StringID joining to LH2 dialogue text. The 2026-10-28 original EU audit resolves all 14,283 distinct-payload ALB records, covering 7,314 individual dialogue streams. This numeric join is established independently of AudioMap. CTB event selection, composite IGC subtitle timing and other playback conditions remain unresolved. Mix metadata (.mib) and Character audio metadata (.rcm_b) add mix/character-audio context; their exact joins are unresolved. AMB resource (.amb) and AUB resource (.aub) must be identified from their own bytes rather than treated as ALB variants.

The audio directory page describes the maintained AudioMap registry used for organization. AudioMap rename rules are pipeline metadata; they are not evidence of the binary ALB/CTB hash algorithm or a substitute for original audio-engine logic.

Interactive music

Interactive music metadata (.msb) packages EA Pathfinder interactive music state-machine logic. Every .msb container in the PS3 EU dataset pairs 1-to-1 with an external MUS container: the MSB wrapper header names the target .mus archive at 0x30, section 7 stores a 4-byte MusFileId checksum matching the first 4 bytes of the MUS header, and section 8 replicates the exact segment count, TOC raw SNS offsets, and segment millisecond durations (allowing Pathfinder to time transitions without decoding audio waveforms). MUS holds descriptors for paired SNR metadata and SNS audio payloads. The inspected BMS implementation reads descriptors at 0x28, scales the SNR offset by 0x10 and SNS offset by 0x80, then extracts each pair. That implementation extracts individual segments; it does not execute the MSB state machine or reconstruct adaptive runtime track transitions.

Rendered assets, scenes and effects

Preinstanced models (.dff/.rws) package Criterion RenderWare 3.7.0.2 Clump streams extended with EA EARS (EA Render Studio) custom plugins. Each submesh MaterialId maps 1-to-1 to an rwID_MATERIAL in the RenderWare material list, which holds primary diffuse texture names and optional alpha masks resolved against TXD texture dictionaries. The geometry payload (EA_EARS_MESH / 0x0000EA33) partitions into a CPU metadata buffer (Buffer 1) and GPU vertex/index streams (Buffer 2), linked dynamically by an 8-byte pointer relocation table (mDataTable). Compiled MetaModel (.meta.xml) properties and Simulation group (extracted .dat.simgroup; legacy .dat) instances provide additional object/scene concepts; a geometry import alone does not reconstruct those systems around a mesh.

Impact resource (.imb) contains candidate material/effect clusters; Effect bundle (.vfb) contains named effect blocks and timing-like parameters. An impact-to-effect/audio join is plausible but the hash algorithms and target IDs are unresolved. Decoding geometry or a sound stream does not reconstruct an effect player.

Character motion and collision

Bone bindings (.bbn.PS3) joint names, Animation bank (.bnk.PS3) animation/state names, Controller event configuration (.cec.ps3) events and Character/controller resource (.rcb.PS3) CCT-export resources describe complementary character-system data. Exact numeric joins and compressed animation decoding are not established. These animation banks are distinct from SBK audio banks.

The 2026-10-22 collision audit distinguishes two routes. HKT and HKO use wrapped Havok packfiles with section-relative fixups and typed shape objects. The inspected HKT mesh arrays provide triangle collision independently of the visual mesh; the repeated HKO named char_collision_spheres actually contains boxes and spheres. These bounded samples do not establish a universal static/animated suffix distinction.

Bunny ACS primitive records use a separate non-Havok layout. Their binding IDs join to BBN aliases and rig hashes, then to little-endian HAnim node IDs in both inspected bunny LODs. This numeric attachment chain is byte-validated; bone poses, skinning remaps, coordinates and runtime collision rules remain unresolved. Other ACS identifiers may resolve directly to rig hashes, so preserve the identifier namespace per sample.

World organization, sequences and interface

Spatial partition resource (.bsp) spatial structures, Navigation graph (.graph) navigation nodes and Table-of-contents resources (.toc) streaming/occlusion indexes describe related level space with different data models. No shared node numbering or automatic coordinate transform is established. The octc/occl TOC family must be separated from generic stream TOCs and STR's own section directory.

Compiled sequence resource (.xml.PS3) has observed seqm/seqb blocks, whereas binary MetaModel data uses a different layout despite its .meta.xml name. Shock resource (.shk.PS3) command records may belong to sequencing logic, but no common opcode mapping is demonstrated. Compiled APT interface (.uix) contains APT and UI resource/font-name strings; full module-to-font/texture resolution and UI execution remain separate work.

Shared data conventions and common traps

Conventions to preserve when following a reference
Data How to interpret it
32-bit IDs / hashes Join only within a verified namespace. Lowercase SDBM is validated for the documented TOX dialogue labels and the inspected npc_default BBN rig/alias names; it is not a proven universal algorithm for material, bone, audio and object identifiers. Preserve byte order at each join: the bunny's BE BBN rig hashes match LE HAnim node IDs.
Offsets Record whether a value is file-absolute, section-relative, mesh-relative or scaled. LH2 pointers are absolute; MUS SNR/SNS offsets have different units. Never infer a pointer base from the integer width.
Text and glyph codes LH2 text uses observed Windows-1252 bytes; INF has custom character remaps and controller glyph aliases. Decoding text and selecting glyphs are separate operations.
Byte order / floats PS3 files are not uniformly big-endian. RenderWare framing, native texture fields and preinstanced model fields can differ. Preserve unknown words rather than assigning meanings from familiar float values alone.
Timing / coordinates TOX start/duration values are milliseconds. INF texture coordinates are 12.4 fixed-point pixels. VFX timing and world transforms need their own validation; do not transfer units between formats.
Compound suffix / path UID Use the complete suffix to distinguish .bnk.PS3, .tox.PS3 and .dff.PS3.preinstanced. A normalized six-hex filename suffix identifies path context; it is not automatically an embedded StringID.

See the optional Remake Engine integration for implementation-specific commands and outputs. Cross-platform concepts can overlap while native layouts differ; compare Xbox ITXD with PS3 TXD before sharing a decoder.
