Game format research · PS3 EU reference baseline

Maps 32-bit string IDs to localized text and internal labels for interface text, objectives/tutorials, FMV dialogue and individual in-game voice lines.

Identification
2HCL at 0x00; 32-byte header, ID array and absolute string-pointer matrix.
Byte order / text
Big-endian integers; NUL-terminated Windows-1252 text in the observed PS3 tables.
Documentation scope
Original PS3 EU structures and dialogue joins were audited on 2026-10-28. Usable data reading does not establish every field's semantics or original runtime behavior; see the evidence and limitations below.

Evidence and limitations

Operation 8 exports table columns without assigning language names. Operation 10 reads the first column of selected global language files directly, so it does not depend on operation 8 CSV output. A language suffix alone does not prove the contents of every table. Runtime fidelity of operation 8 remains to be checked: its binary integer reader uses string.byte, whereas the newer INF/TOX converters use string.unicode and explicitly document the host's high-byte handling. The structural sample checks do not execute that Lua reader.

Detailed field tables and retained samples are research evidence. Implementation-derived observations must remain attributed to their tools; tentative, observed and contextual relationships do not establish complete original runtime behavior. Offsets in the added tables are zero-based; range ends are exclusive unless stated otherwise.

LH2 maps 32-bit IDs to columns of strings. The observed PS3 signature is 2HCL, with big-endian integers and absolute offsets measured from the start of the file.

Header and identification

32-byte LH2 header; offsets are zero-based
Offset Type Meaning
0x00 char[4] Magic 2HCL.
0x04 uint32 BE Declared file size. Operation 8 warns when it differs from the actual length; it is not padding.
0x08–0x0F byte[8] Not interpreted by the current converters.
0x10 uint32 BE EntryCount (N): number of IDs.
0x14 uint32 BE TableCount (T): number of string columns.
0x18–0x1F byte[8] Reserved/runtime fields skipped by operation 8; runtime purpose not verified.

ID array, pointer matrix and strings

The ID array begins at 0x20 and contains N unsigned 32-bit values. The pointer matrix begins at 0x20 + 4*N. Columns are stored consecutively: table 0 has N pointers, then table 1 has N pointers, and so on. Pointer (t,e) is at 0x20 + 4*N + 4*(t*N + e) and points to a NUL-terminated string at an absolute file offset.

Before reading strings, check that 0x20 + 4*N*(1+T) fits inside the file and that every referenced offset and terminator is in bounds. A zero-entry table is distinct from an invalid/truncated header. Shared pointers do not imply duplicate IDs.

Text columns and language variants

LH2 is a general localization resource, not exclusively a movie-subtitle format. Original global labels include MENU_MAIN_CONTINUE_STORY, tutorial_one_LOC and CREDITS_IntEngineers_1; dialogue tables also contain incidental speech and scripted in-game lines. Table contents alone do not establish which lines the original game actually displays as subtitles.

The EU flattened inventory contains 654 LH2 files: 554 without a language suffix and 20 each with .en, .es, .fr, .it and .ss. The four language variants supply English, Spanish, French and Italian. The observed global .ss.LH2 table supplies internal labels, not an additional Spanish translation.

The original-source duplicate audit identifies five global STRs repeated across 20 directories and records their hashes and paths. The 654 occurrences do not represent 654 distinct LH2 byte sequences.

Operation 8 writes original.LH2.csv beside the source. It emits an eight-digit hexadecimal String ID and Language 0 onward. For multiple columns it treats the final column as String Label; that is a converter convention, not a guaranteed meaning of every LH2 table. Its reader preserves source characters without an explicit CP1252 control-range remap. Operation 10 explicitly decodes Windows-1252 when producing subtitle text.

Operation 10 selects the first non-empty path-sorted global table for each supported language/label column, reads only its first table, and joins on the numeric ID. It does not merge all duplicate localization copies. The lowercase SDBM label/hash relationship is validated for the TOX dialogue labels described on the timing page; do not generalize that result to every unidentified ID in every format.

Original dialogue audio-to-subtitle mapping

Original-byte audit, 2026-10-28: all 550 STR archives beneath ps3-eu-original:PS3_GAME/USRDIR were walked and relevant payloads decoded directly. The 654 LH2 occurrences reduce to 346 distinct payloads: 341 five-column tables and five single-column global variants. The five-column tables contain 7,420 distinct IDs with columns English, French, Italian, Spanish, internal label. Every label in those tables reproduces its ID using lowercase SDBM (h = (h * 65599 + byte) mod 2^32, initially zero). This validates this table population; it is not a universal hash claim.

ALB record +0x04 bank ID, +0x08 stream ID
    └── equal SMB record +0x04 bank ID, +0x08 stream ID
          └── SMB record +0x34 names the .exa stream; original file adds .snu
ALB record +0x14 StringID
    └── equal LH2 ID → localized text and internal label

The join uses the original numeric fields, not AudioMap, speaker guesses, filename sequence numbers, normalized suffixes or a custom subtitle map. The three stream-ID words at ALB/SMB record +0x08/+0x0C/+0x10 are equal throughout this audit; their separate runtime roles remain unknown. Preserve the bank ID when joining. ALB record +0x00 is a separate alias identifier.

All 529 ALB occurrences (519 distinct payloads; 14,333 records including duplicate payloads, 14,283 after payload deduplication) have the 24-byte layout. All 14,283 records resolve to SMB filenames and five-column LH2 text, covering 7,314 distinct dialogue SNU filenames and StringIDs. Each recovered name also equals d_<LH2 internal label>.exa; this is an independent consistency check on the numeric join. The trailing seven hexadecimal characters of a dialogue filename are not its LH2 StringID.

Worked original-file example

In original PS3_GAME/USRDIR/bargainbin/bargainbin.str, section 5 contains eps_bin_brt8.alb, bargainbin.smb and {CF608FDC-8FDC-CF60-DC8F-60CFDC8F60CF}.LH2. The exact embedded member paths, original archive/payload hashes and source coordinates are retained in the locally generated audit report described under reproducing the original-source audit.

  • ALB payload record 0x98: alias C9FE2D88, bank 6AA373D3, stream 37485CCE, StringID C9EAD80F.
  • SMB payload record 0x1180: the same bank/stream pair; filename at 0x11B4 is d_brt8_xxx_00033c4.exa.
  • LH2 row 1: ID C9EAD80F, label brt8_xxx_00033c4, English text “Cowabunga! I need help! Cowabunga!”
  • Original English audio: PS3_GAME/USRDIR/audiostreams/t8_xxx_0/d_brt8_xxx_00033c4.exa.snu. FR/IT/ES counterparts are beneath those language directories. English banks are directly beneath audiostreams in this source.

Coverage and remaining gaps

The 99 SMB payloads contain 14,382 records and name all 7,413 distinct original SNU filenames (29,430 physical files across language/global scopes). The remaining 99 filenames lack this ALB-to-LH2 link: 34 composite IGC tracks, 64 ambience/music streams and d_nels_xxx_000683f.exa. That Nelson label is also absent from the inspected five-column LH2 tables. Absence here is not evidence that no subtitle exists elsewhere. Some physical language copies are absent; filename coverage is not four-language inventory parity.

The other 106 five-column LH2 IDs all have labels containing _igc_; they have no recovered ALB link. None of the 34 composite SNU stems equals one of the 43 distinct TOX stems in the original archives. The existing FMV TOX association therefore does not directly supply these SNU timelines. Text presence and clock recovery remain separate questions.

Composite cutscenes need sequence/timing analysis; do not assign a single dialogue row to a whole IGC mix or assume an FMV TOX is its timeline. VP6/TOX movie audio, SBK subsongs and MUS/SNR/SNS music remain separate resource families. CTB event selection, interruptions and original subtitle dwell times are not established by this static join. No original executable behavior was observed.
