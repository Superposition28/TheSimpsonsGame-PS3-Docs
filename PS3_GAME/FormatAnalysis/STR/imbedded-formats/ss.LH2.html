Evidence and limitations

The inventory below was read from the local EU flattened dataset. It is not a universal regional inventory. File paths retain their normalization hashes; the six-hex suffix is not an LH2 StringID.

Operation coverage is grounded in the module manifest and its referenced implementations. Detailed field tables and retained samples below/above are the existing research evidence; labels such as tentative, observed and context must not be read as a complete runtime implementation. Offsets in the added tables are zero-based; range ends are exclusive unless stated otherwise.

This variant uses the shared LH2 binary layout. The observed simpsons_global.ss.LH2 data contains internal labels such as CREDITS_IntEngineers_1. Operation 16 uses it to name cues and derive speaker labels; it is not emitted as a fifth subtitle language.

Variant identification

Match the full .ss.LH2 compound suffix, allowing the six-hex normalization hash before it. Do not confuse language suffixes with arbitrary unsuffixed LH2 tables; column meaning is a content-level property.
