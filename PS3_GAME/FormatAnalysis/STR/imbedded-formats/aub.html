Game format research · PS3 EU reference baseline

Electronic Arts SoundFX master audio bus configuration and DSP routing graph, defining mix buses, parent categories, volume parameters, and acoustic reverb zones.

Identification
Header with ASCII magic SSFX (0x53534658) at offset 0x1C, declared bus count (55) at offset 0x10, category count (5) at offset 0x14, and contiguous 100-byte bus records starting at offset 0x80.
Byte order / text
Big-endian 32-bit words, IEEE 754 single-precision floats, and null-padded ASCII bus and category names.
Documentation scope
Exact layout, 55 audio buses, and 23 DSP routing/zone nodes verified against both global.aub instances in the PS3 EU baseline on 2026-11-03.

Format Structure & Breakdown

The .aub (Audio User Bus) format serves as the master configuration file for the game's audio mixer and DSP engine. It defines the complete hierarchy of sound categories, individual mix channels/sub-buses, dynamic ducking parameters, and environmental reverb zones.

Container Header (0x00..0x7F, 128 bytes)

AUB container header
Offset Type Field name Observed value & description
0x00..0x0F 16 bytes ReservedWords Header preamble (includes group count 0x0C at 0x08 and channel index 0x0A at 0x0C).
0x10 uint32 BE BusCount Number of audio bus records in the table (universally 55 / 0x37).
0x14 uint32 BE CategoryCount Number of parent mix categories (universally 5).
0x18 uint32 BE ConfigFlags Configuration word (universally 0x00000006).
0x1C char[4] Magic ASCII magic identifier SSFX (0x53534658, Simpsons SoundFX).
0x20..0x7F 96 bytes Padding Null padding aligning the bus table to offset 0x80.

Audio Bus Table (55 Entries, 100 Bytes Each)

Starting at offset 0x80 and extending to 0x15FB (5,500 bytes total). Each entry is an exact 100-byte (0x64) record:

Audio bus entry layout (100 bytes)
Offset Type Field name Description
0x00..0x3F char[64] BusName Null-padded ASCII bus identifier (e.g., MUSIC_SCORE, VO_PC_CHATTER_HOMER, CHAR_FOOTSTEPS).
0x40..0x5F char[32] CategoryName Null-padded ASCII parent mix category (e.g., MUSIC, DIALOG, SFX, UI_MASTER).
0x60..0x63 uint32 BE Parameter Volume attenuation / ducking priority parameter (IEEE 754 float or integer flags).

Master DSP Graph & Acoustic Zones

Starting at offset 0x15FC through EOF (1,704 bytes), the file contains the DSP processing graph, acoustic reverb spaces, and channel routing definitions:

  • Environmental Acoustic Presets: Zone_Med, Model1Reverb with space size attributes (ATTRIBUTE_SETSPACESIZE) and send gains (ATTRIBUTE_SETGAIN).
  • Master Dynamic Processing: MASTERING, MasterCompressor with compression ratios (ATTRIBUTE_SETRATIO), release times (ATTRIBUTE_SETRELEASETIME), and PostCompressionGain.
  • Equalization & Filtering: GeneralPurposeLowpass filters with gain and pitch controls (ATTRIBUTE_SETPITCH).
  • Routing & Channel Groups: DISCRETE_CHANNELS, TIMESTRETCHED_CHANNELS (with Timestretch and Resample), RAMGENERIC, GENERIC_STREAMS, and SUBMIX1.
