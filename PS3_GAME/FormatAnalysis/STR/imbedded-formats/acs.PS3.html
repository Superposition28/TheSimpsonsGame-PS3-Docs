Format: ACS ╬ô├ç├╢ per-character Articulated Collision Shapes (PS3)

marge.acs.PS3 is a small, binary list of simple hit-shape primitives (mostly spheres/capsules) attached to a character╬ô├ç├ûs bones. The game uses this to do lightweight gameplay collision (melee hits, pickups, proximity checks, cursor targeting, etc.) without touching the full Havok meshes.

Why this is ACS / hit-spheres

  • The path: assets\shared\collision\marge.acs.PS3 ╬ô├Ñ├å per-character collision set.

  • You see lots of IEEE-754 floats like:

    • 3F 80 00 00 = 1.0 (identity scale/weights),
    • 3E 99 99 9A ╬ô├½├¬ 0.30, 3E 80 00 00 = 0.25, 3F C0 00 00 = 1.5, 3D CC CC CD = 0.1 ╬ô├ç├╢ typical radii for gameplay spheres.

  • Repeating fixed-size records with very similar layouts (centers/flags/identity), suggesting ╬ô├ç┬úone primitive per bone╬ô├ç┬Ñ.

What the game uses it for

  • Hit detection / hurtboxes for punches, kicks, and small overlaps.
  • Targeting helpers for abilities and cursor hover.
  • Cheap per-bone checks while Havok handles full body collision separately (your .hkt file).

Rough layout you╬ô├ç├ûre seeing (per entry)

Not exact names, but the pattern maps like this for each shape:

  • A small header/IDs (includes a bone or binding hash; EA often stores CRCs of bone names).
  • A primitive type code (you╬ô├ç├ûll spot 0x73 00 00 ╬ô├Ñ├å 's' = sphere; some titles also use 'c' for capsule).
  • Center/orientation-ish block (many 1.0 values ╬ô├Ñ├å identity) and/or flags.
  • A radius (those 0.25 / 0.30 / 0.10 / 1.50 values).
  • Repeats for each bone hotspot (head, hands, forearms, torso, legs, etc.).

In short: .acs.PS3 = fast hit-shape set╬ô├ç├╢a handful of bone-attached spheres (and possibly capsules) used by the EA/RenderWare runtime for quick overlap tests and gameplay interactions on PS3.

related extensions:

  • .hkt.PS3 all regular collision files have this extension
  • .hko.PS3 all animated collision files have this extension, and all character collision spheres use this extension
  • .acs.PS3 always contained within collision folders (or subfolders of it) often alongside .hko.PS3 files
