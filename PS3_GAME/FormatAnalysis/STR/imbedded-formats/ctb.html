Game format research · PS3 EU reference baseline

Audio control and chatter trigger table linking high-level game events (e.g., pc_sighted, taunt, react_cake) to sound aliases cataloged in corresponding .alb libraries, complete with 3D spatial attenuation and playback parameters.

Identification
Big-endian version 6 (0x0006) at offset 0x00, declared cue count at offset 0x10, fixed 44-byte cue record array starting at offset 0x38, packed uint32 sound alias tables, and trailing null-terminated ASCII event names.
Byte order / text
Big-endian 16-bit and 32-bit integers, IEEE 754 single-precision floats (volume, pitch, min/max attenuation distances), and null-terminated ASCII event strings.
Documentation scope
Complete binary specification, 44-byte record stride, and alias resolution verified across all 528 .ctb files (6,802 event cues, 14,330 sound aliases) in the PS3 EU baseline on 2026-11-03.

Format Structure & Breakdown

The .ctb (Audio Control Table) format defines playback logic and triggers for character dialogue, vocal chatter, and level sound cues. It is structured into four sequential zones:

  1. Container Header (0x00..0x37): Declares file version, cue count, default gain, and global speaker configuration.
  2. Cue Records Array (0x38..): Array of cue entries stored in 44-byte (0x2C) slots, specifying cue mode tags, string offsets, ID array offsets, and 3D spatial attenuation floats.
  3. Sound Alias ID Table: Contiguous arrays of packed 32-bit big-endian sound alias IDs referenced by each cue.
  4. String Table: Packed null-terminated ASCII strings containing human-readable event names (e.g., attacked_knockdown, taunt, pc_sighted).

Container Header (0x00..0x37, 56 bytes)

CTB container header structure
Offset Type Field name Observed value & description
0x00 uint16 BE Version Universally 6 (0x0006), matching the format version of .alb.
0x02 uint16 BE Subtype Universally 0x0000.
0x04..0x0F 12 bytes ReservedPreamble Null padding (universally 0x00).
0x10 uint16 BE CueCount Number of event cue records defined in the file (observed range: 1 to 49).
0x12 uint16 BE CategoryFlags Dialogue category flags / channel routing mode.
0x14 uint32 BE HeaderParam Header parameter; universally 0x00000018 (24).
0x18 uint32 BE AssetHash Primary character or episode audio asset hash.
0x1C float32 BE DefaultGain Default master playback volume/gain (commonly 1.0 or 0.0).
0x20..0x37 24 bytes GlobalSpatialConfig Global 3D listener and rolloff parameters (IEEE 754 floats).

Event Cue Records (0x38..Payload, 44-byte Stride)

Cue records start at offset 0x38. Each intermediate cue record occupies a fixed 44-byte (0x2C) slot. The final record in the array has a 12-byte header immediately preceding the start of the sound alias ID table.

CTB event cue record structure
Offset Type Field name Observed value & description
0x00 uint8 Tag Cue execution mode tag (e.g., 0x50 = 'P' [Play], 0x55 = 'U', 0x5A = 'Z', 0x5B = '[').
0x01 uint8 Subtype Playback variation mode / trigger condition flags.
0x02 uint8 SecondaryCount Variant weight / stride parameter.
0x03 uint8 SoundAliasCount Exact number of uint32 sound alias IDs belonging to this cue in the alias table.
0x04 uint32 BE StringOffset Absolute byte offset from file start to the null-terminated ASCII event trigger name.
0x08 uint32 BE SoundAliasOffset Absolute byte offset from file start to the array of 32-bit sound alias IDs.
0x0C uint32 BE TargetHash Speaker persona hash or target character entity identifier.
0x10 float32 BE Volume Cue playback volume / attenuation scalar (e.g., 1.0, 10.0).
0x14 float32 BE PitchOrPan Playback pitch multiplier or stereo pan bias.
0x18 float32 BE MinDistance 3D sound minimum attenuation distance (inner radius).
0x1C float32 BE MaxDistance 3D sound maximum audible distance (outer cutoff radius).
0x20..0x2B 12 bytes AttenuationFloats Rolloff curve factor and directional cone parameters.

Sound Alias Tables & Event Names

Following the cue records table, contiguous arrays of 4-byte big-endian sound alias IDs are stored. Each cue reads exactly SoundAliasCount IDs starting from SoundAliasOffset. These IDs correspond directly to sound entries defined in the episode or character's paired .alb library.

The final section of the file holds packed null-terminated ASCII strings containing the descriptive event triggers (e.g., pc_sighted, taunt, attacked_knockdown, react_cop). Pointers in StringOffset reference the start of each string.
