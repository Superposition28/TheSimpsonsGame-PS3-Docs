Overview & Purpose

.tox.PS3 is Electronic Arts' binary subtitle timing table used in The Simpsons Game (PS3) to synchronize localized subtitles during pre-rendered On2 VP6 Full-Motion Video cutscenes and mission briefings. Companion movies are stored under A1_Video/{en,es,fr,it,sf}/*.vp6; extracted / converted video collections also contain .ogv copies. The magic bytes are 1BOT (31 42 4F 54), or "TOB1" when interpreted as a Little-Endian 32-bit FourCC. Numeric fields are Big-Endian.

The table contains timing and string IDs; subtitle text lives in companion .LH2 localization files. StringID identifies a dialogue label, not a text offset or an audio filename. operations/tox_to_srt.Subtitles.lua resolves all timing tables against simpsons_global.{en,es,fr,it,ss}.LH2 and exports standard SubRip (.srt), WebVTT (.vtt), and multilingual .csv files, including .srt/.vtt files directly alongside matching localized .ogv/.vp6 streams in A1_Video/{en,es,fr,it}/.

Binary Structure (Big-Endian)

The file consists of a 16-byte header followed immediately by RecordCount contiguous 16-byte timing records. There are no string payloads, record pointers, or trailing bytes. Offset ranges below use an exclusive upper bound.

16-Byte Header (0x00..0x10)

16-byte header: [0x00, 0x10)
Offset Type / Size Field Meaning / Validated Value
0x00 char[4] / 4 Magic 1BOT (31 42 4F 54); Little-Endian 32-bit FourCC TOB1.
0x04 uint32 BE / 4 FileSize Exact total file size in bytes; FileSize == 16 + RecordCount * 16 in all 77 files (100%).
0x08 uint32 BE / 4 Reserved Always 0x00000000 in all 77 files.
0x0C uint32 BE / 4 RecordCount Number of 16-byte timing records; observed range 0–41.

16-Byte Timing Record Array (0x10..EOF)

Array size: RecordCount * 16 bytes. Zero-based record i starts at 0x10 + i * 0x10.

16-byte timing record: array begins at 0x10
Relative Offset Type / Size Field Meaning / Validated Value
+0x00 uint32 BE / 4 StringID 32-bit lowercase SDBM hash (multiplier 65599, seed 0) of an internal IGC dialogue label; e.g. moes_igc_000302f → 0x3F02A918.
+0x04 uint32 BE / 4 StartTimeMs Display start in milliseconds from the beginning of the companion .vp6 video stream.
+0x08 uint32 BE / 4 DurationMs Display duration in milliseconds; EndTimeMs = StartTimeMs + DurationMs.
+0x0C uint32 BE / 4 FlagsOrConstant Always 0x0012FF30 (1,244,976) across all 825 records in all 77 files.
Constant interpretation: The bytes 00 12 FF 30 are fully verified; their provenance is an inference. 0x0012FF30 resembles an uninitialized 32-bit stack-pointer value copied by EA's offline Windows x86 exporter, or a fixed runtime placeholder. No changing flag bits or rendering semantics have been demonstrated. Preserve the value when reproducing this corpus.

Timing units are milliseconds, not frames. Preserve each start and duration independently; use start + duration for its end. Do not derive one cue's end from the next cue's start or force a uniform inter-cue gap. Header-only files are valid empty tables, not truncated data.

Exact Hash Algorithm: Lowercase SDBM (Multiplier 65599)

Correction to the preliminary notes: StringID is not FNV-1. Comparing all 3,352 global labels in simpsons_global.ss.LH2 and all 554 multi-table .LH2 files (14,439 entries) establishes a 100% match to case-insensitive, lowercased SDBM with multiplier 65599, initial seed 0, and 32-bit wraparound.

.ss.LH2 stores raw internal labels instead of Spanish text; Spanish is .es.LH2. Lowercase the label, encode it as Windows-1252, and accumulate each byte:

def sdbm_hash_lower(label: str) -> int:
    h = 0
    for ch in label.lower().encode("cp1252"):
        h = (h * 65599 + ch) & 0xFFFFFFFF
    return h

Every timing record hashes a label of the form <speaker>_igc_<7_char_id>. Speaker prefixes include bart, homr, moes, dman, godx, gron, shak, and grmp. Use the exact label spelling; the Willie label in the worked example is wili_igc_0003036.

Cross-Reference with .LH2 Localization & .vp6 Movies

Join the Big-Endian StringID to the same ID in simpsons_global.en.LH2, .es.LH2, .fr.LH2, and .it.LH2 for English, Spanish, French, and Italian text. Join to simpsons_global.ss.LH2 for the original internal label and speaker prefix. Extraction may append a six-hex-digit suffix before the extension, e.g. simpsons_global_3fc164.ss.LH2.

Direct global-table coverage is 824 / 825 timing records and 397 / 398 distinct IDs. After identifying the one cut cue by its exact SDBM label, all 398 timing IDs are accounted for, but that cue still has no localized text. Video matching uses the cleaned movie stem after removing the extraction suffix, not the subtitle StringID.

The Single Unmatched Localization Record: 0xE6A49A45

In gam_igc04_db5067.tox.PS3, zero-based record #26 (the 27th and final entry, at file offset 0x1B0) begins at 80,612 ms, lasts 1,000 ms, and ends at 81,612 ms. The preceding zero-based records #22..#25 are the 1,000 ms falling screams into the Game Engine portal:

sdbm_hash_lower("bart_igc_000602e") == 0xE6A49A45. The global tables jump directly from bart_igc_000602d (0xE6A49A44) to bart_igc_000602f (0xE6A49A46), omitting 000602e. This identifies the leftover cue as a cut one-second Bart scream. The converter recovers its label for CSV reporting and skips the missing text in SRT / VTT output.

  • 6 bonus tables, making_01 through making_03 and their _sd variants, exist only in Frontend. Each is exactly 16 bytes with RecordCount = 0. The unsubtitled featurettes making_01, making_01_sd, making_03, and making_03_sd have movies in A1_Video/sf/; making_02 and its SD variant were cut from the disc.

Their dialogue was merged into che_igc01 (opening 15 lines at Frink's house), bin_igc01 (opening 27 lines before entering the Game Engine), and mtp_igc01 (closing 11 lines at the Stairway to Heaven), respectively. Illustrative Python Parser

This self-contained example combines the SDBM function above with strict corpus validation and single-table global LH2 lookups. It writes SRT, WebVTT, and multilingual CSV next to one timing file. The constant / reserved checks below enforce observed PS3 corpus invariants rather than claiming rules for unexamined platforms.

from pathlib import Path
import csv
import struct

def read_tox(path: Path) -> list[tuple[int, int, int, int]]:
    data = path.read_bytes()
    if len(data) < 16 or data[:4] != b"1BOT":
        raise ValueError("Invalid or truncated 1BOT header")
    size, reserved, count = struct.unpack_from(">III", data, 4)
    if size != len(data) or size != 16 + count * 16:
        raise ValueError("FileSize / RecordCount mismatch")
    if reserved != 0:
        raise ValueError("Unexpected reserved field for this PS3 corpus")
    rows = list(struct.iter_unpack(">IIII", data[16:]))
    if any(flags != 0x0012FF30 for _, _, _, flags in rows):
        raise ValueError("Unexpected record constant for this PS3 corpus")
    return rows

def read_global_lh2(path: Path) -> dict[int, str]:
    # Single-table simpsons_global.{en,es,fr,it,ss}.LH2 only.
    data = path.read_bytes()
    if len(data) < 0x20 or data[:4] != b"2HCL":
        raise ValueError("Invalid LH2 header")
    count, tables = struct.unpack_from(">II", data, 0x10)
    if tables != 1 or 0x20 + count * 8 > len(data):
        raise ValueError("Expected a complete single-table global LH2")
    result = {}
    for i in range(count):
        sid = struct.unpack_from(">I", data, 0x20 + i * 4)[0]
        ptr = struct.unpack_from(">I", data, 0x20 + count * 4 + i * 4)[0]
        end = data.find(b"\0", ptr)
        if ptr >= len(data) or end < 0:
            raise ValueError("Invalid LH2 string pointer / terminator")
        result[sid] = data[ptr:end].decode("cp1252")
    return result

def timestamp(ms: int, separator: str = ",") -> str:
    seconds, millis = divmod(ms, 1000)
    minutes, seconds = divmod(seconds, 60)
    hours, minutes = divmod(minutes, 60)
    return f"{hours:02}:{minutes:02}:{seconds:02}{separator}{millis:03}"

def export(tox: Path, globals_by_lang: dict[str, Path], labels_path: Path) -> None:
    rows = read_tox(tox)
    labels = read_global_lh2(labels_path)
    labels.setdefault(sdbm_hash_lower("bart_igc_000602e"), "bart_igc_000602e")
    tables = {lang: read_global_lh2(p) for lang, p in globals_by_lang.items()}
    stem = tox.name[:-8]  # Remove .tox.PS3; preserve extraction hash suffix.
    for lang, texts in tables.items():
        srt, vtt = [], ["WEBVTT\n\n"]
        for sid, start, duration, flags in rows:
            text = texts.get(sid, "").strip()
            if not text:
                continue  # Unlocalized cue remains in CSV.
            end = start + duration
            srt.append(f"{len(srt)+1}\n{timestamp(start)} --> {timestamp(end)}\n{text}\n\n")
            vtt.append(f"{labels.get(sid, f'{sid:08X}')}\n"
                       f"{timestamp(start, '.')} --> {timestamp(end, '.')}\n{text}\n\n")
        if rows:
            tox.with_name(f"{stem}.{lang}.srt").write_text("".join(srt), encoding="utf-8")
            tox.with_name(f"{stem}.{lang}.vtt").write_text("".join(vtt), encoding="utf-8")
    with tox.with_name(tox.name + ".csv").open("w", encoding="utf-8", newline="") as out:
        writer = csv.writer(out)
        writer.writerow(["StringID", "Label", "StartMs", "DurationMs", "EndMs", "Flags", *tables])
        for sid, start, duration, flags in rows:
            writer.writerow([f"{sid:08X}", labels.get(sid, ""), start, duration,
                             start + duration, f"0x{flags:08X}",
                             *[texts.get(sid, "") for texts in tables.values()]])
