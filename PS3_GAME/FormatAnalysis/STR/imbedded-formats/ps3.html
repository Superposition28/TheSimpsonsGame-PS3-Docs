Evidence and limitations

Identify the preceding suffix (.tox, .bnk, .hkt and so on) before choosing a parser. Counts and support vary by resource type.

Detailed field tables and retained samples are research evidence. Implementation-derived observations must remain attributed to their tools; tentative, observed and contextual relationships do not establish complete original runtime behavior. Offsets in the added tables are zero-based; range ends are exclusive unless stated otherwise.

.PS3 identifies the platform build of several resource families. It does not define one shared file format, endian mode or decoder. Read the full compound suffix before selecting a parser.

Family Suffixes Current scope
Character motion/control .bbn.PS3, .bnk.PS3, .cec.ps3, .rcb.PS3 Binding, animation and controller research; no registered animation/control conversion.

The format index links each family separately. Cross-platform .XEN resources require their own layout checks; replacing a filename suffix does not translate native data.
