A1_Video: movies and localized media

Source scope: PS3 EU, paths relative to ps3-eu-extracted:A1_Video/. Supplementary US observations below retain their labels. This migration reconciled filenames, not every historical inventory claim.

The original movies directory contains video assets. Its canonical extracted group is A1_Video. The movie filenames in the inventory below use ps3-eu-extracted; flattened aliases were reconciled through the normalizer map.

VP6 stores movie media. TOX holds timing and string IDs; LH2 supplies localized text. INF and texture atlases are separate rendering resources, not embedded subtitle tracks.

Logos, attract loops and special-feature clips may have no active subtitle table. The list below is an observed EU inventory, not a guarantee that every clip has subtitles in every region.

in the EU version of the game there are 5 folders within the movies/A1_Video folder:

  • en: english
  • es: spanish
  • fr: french
  • it: italian
  • sf: special features? contains trailer like videos and similar clips found in the start menu attractloop

the US version only has en, no other languages, and no sf folder
