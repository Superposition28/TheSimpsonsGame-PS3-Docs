A2_Frontend (frontend)

Frontend resources combine interface modules, shared fonts/textures and menu-related assets. UIX font-name strings are observations; a complete UIX-to-INF resource resolver is not implemented. Operation 15 converts INF with a matching PNG atlas, while LH2 supplies localized strings.

See localized text and fonts and interface resource relationships. Converting an atlas or FNT alone does not reproduce the original menu behavior.

Contains front-end menu archives (frontendStr, frontendGlobalStr), APT UIX layouts, texture dictionaries, and shared menu/subtitle typography.
