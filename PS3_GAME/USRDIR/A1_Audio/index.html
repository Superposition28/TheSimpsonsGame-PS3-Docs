AudioMap Registry

View AudioMap.yaml

The registry maps English dialogue and Global ambient resources to their original directory names, character or sound labels, game levels, and filename patterns.

  • Character records cover playable characters, Springfield NPCs, enemies, and level-specific variants.
  • Dialogue entries record the source folder, output grouping, known character, level context, and matching .exa.snu filename patterns.
  • Cutscene and Global sections document named streams and ambient sound resources by level and location.

Pipeline Usage

The SetupAudioDir.lua script loads this YAML during the Reorganize Audio Files operation. If the file is missing, cannot be parsed, or contains no usable Dialogue rules, the map-based rename phases are skipped.

  • Dialogue rules are applied in each detected EN, ES, FR, and IT folder.
  • CUTSCENE rules are applied in the same language folders.
  • Global-Sound rules are applied in Global without character subfolders.

Rename Rule Fields

  • OLD_DIR_NAME identifies the source folder and NEW_DIR_NAME names its destination. A blank or TBD destination falls back to the source name with a trailing _xxx_0 removed.
  • For Dialogue and CUTSCENE rules, a usable CharacterName creates a character subfolder when its file_patterns.file_pattern matches a file. Empty, unknown, TBD, and TBA names are not used as folder names.
  • In file_pattern, ####### matches a seven-digit hexadecimal line identifier. The current Lua renamer does not use file_regex or file_glob.
