A1_Audio: audio resources and associations

Reference scope: PS3 EU asset/use analysis. New paths use ps3-eu-extracted. Retained inventories may contain Full and FullFlattened paths and generated outputs; those historical examples remain non-canonical until reconciled. Path roots and provenance.

A1_Audio is the canonical extracted group for streamed dialogue, ambient resources and music. Its original source group is audiostreams. EN/ES/FR/IT and Global organization in this dataset includes processing conventions; verify original paths separately.

See audio relationships for ALB/CTB/SMB metadata and audio naming associations. Tool-specific processing belongs in the optional Remake Engine integration.

AudioMap Registry

View AudioMap.yaml

The V2 registry records 242 assets and 144 speaker identities, with original directory names, character or sound labels, game usage and filename patterns. Its JSON Schema defines the maintained data contract.

  • Character records cover playable characters, Springfield NPCs, enemies, and level-specific variants.
  • Dialogue assets reference stable speaker IDs and keep speaker type, variants and uncertain identity separate from game usage.
  • Each asset declares dialogue, cutscene, ambience, sound effect, music or unknown classification, source scope and matching .exa.snu patterns. Unknown usage is distinct from an explicitly empty usage list.

Consumer contract

AudioMap.yaml remains at this path using schema_version: 2. Historical fields and unconsumed metadata are retained under legacy records; the original V1 snapshot remains available as research history. Its character, level and stream associations serve the game reference. The Remake Engine consumer contract records V2 output paths and execution behavior.

The reference includes EN/ES/FR/IT language groups. Exact cross-language inventory parity has not been established in this migration.
