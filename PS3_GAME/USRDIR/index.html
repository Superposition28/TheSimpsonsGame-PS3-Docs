USRDIR: game files and asset use

Most game data, whether archived or directly accessible, belongs under USRDIR. This tree documents concrete resources, inventories, characters, levels and their use. Binary layouts belong in the complementary format-analysis tree.

Source and paths: PS3 EU is the baseline. Main Files lists original USRDIR names; Folder Organization lists the readable groups in ps3-eu-extracted. They are different namespaces. See source conventions and verified folder mappings.

Major documentation groups follow the extracted reference. Deeper folders receive pages when substantive analysis warrants them; otherwise exact paths are recorded in inventories within the nearest useful page. Documentation depth is not a claim about the depth of the game tree.
