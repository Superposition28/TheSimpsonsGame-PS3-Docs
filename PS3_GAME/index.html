PS3_GAME disc layout

The disc root contains platform metadata and presentation images alongside USRDIR, the main game-data directory. The observed EU and US lists below describe source-disc files, not the normalized remake output.

PARAM.SFO metadata documents the EU, US and demo identities, binary header/index format and TOML reference values. This reference distinguishes platform metadata from the STR archives and other resources under USRDIR.

Game files and extracted resources

STR archives in USRDIR contain resource payloads. Movies and streamed audio can also exist outside those archives. Original paths below are relative to the directory containing PS3_GAME. The canonical extracted view uses readable group names whose mappings are documented separately.

Demo package metadata

The inspected demo places PARAM.SFO at the NPEB90029/ package root beside USRDIR/, rather than inside a directory named PS3_GAME. Its title ID is NPEB90029 and its category value is HG. The shared metadata page compares it with the full EU and US files.
