PS3_GAME disc layout

The disc root contains platform metadata and presentation images alongside USRDIR, the main game-data directory. The observed EU and US lists below describe source-disc files, not the normalized remake output.

PARAM.SFO metadata documents the EU, US and demo identities, binary header/index format and TOML reference values. Metadata is read during initialization, independently of STR asset extraction.

Data flow through the module

STR archives in USRDIR supply most resource payloads. Source movies and audiostreams are copied separately, then folders and filenames are reorganized into A1_Audio, A1_Video, character/frontend, level and hub groups. A flattened path is therefore a pipeline artifact, not necessarily the path shipped on disc.

USRDIR layout explains the folder groups. The relationship guide connects media, localization, fonts, geometry and metadata; the operation reference records how each output is produced.
