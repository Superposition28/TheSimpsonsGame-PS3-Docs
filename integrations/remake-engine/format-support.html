GRAPH Format Documentation

Game format reference

The Godot project enables addons/tsg_graph_importer/plugin.cfg. Its editor plugin registers import_graph.gd as tsg.graph.importer, visible as TSG NavGraph, for the graph extension. The importer saves TSGNavGraph as a binary .res resource at the editor-supplied import-cache path.

The resource exposes guid: String, nodes: Array[Dictionary] and edges: Array[Dictionary]. NavGraphVisualizer can consume it to draw nodes as crosses and edges as straight lines, with visibility/color controls. Importing does not construct an AStar3D, a navigation mesh or an original-game AI controller.

No GRAPH converter is registered in operations.toml; that does not mean import support is absent. Operation 1 extracts the source payload and operation 6 can normalize its path. The Godot editor import is a separate code path. See the operation pipeline for the registered operations.

PS3 metadata (PARAM.SFO)

Game format reference

Initialization operation 0 reads PARAM.SFO through the module's existing metadata reader to help classify PS3 source builds and report title/version information. This is source validation, not an independently registered SFO-to-TOML conversion. The known IDs classify the EU and US full copies and the NPEB90029 demo; fallback title/category heuristics are implementation choices, not PSF format rules.

The reference snapshots are readable as supplied. No new conversion operation is registered by this documentation, and no original PS3 executable analysis is required. See the initialization entry in the pipeline reference.
