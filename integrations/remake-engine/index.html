Extraction and normalization conventions

Full is the documentation's canonical extracted view. FullFlattened is an alternate view produced by additional directory normalization. Base-folder renaming and audio reorganization already occur before flattening. The normalizer's original_path refers to Full, not the disc. Preserve original archive/member identity separately when available.

Flattening can remove build/platform segments, collapse directories, rename texture_dictionary, and append six-hex path-derived suffixes. These suffixes are processing identifiers, not automatically embedded game IDs. The local normalizer JSON maps connect the two extracted views.

AudioMap consumer contract

The registry remains at PS3_GAME/USRDIR/A1_Audio/AudioMap.yaml with its existing schema. The module reads this path directly; moving or changing it requires a coordinated consumer migration.

SetupAudioDir.lua uses Dialogue, CUTSCENE and Global-Sound sections for organization. Missing, unparseable or unusable Dialogue rules skip map-based renaming. Dialogue and CUTSCENE rules apply to detected EN/ES/FR/IT folders; Global-Sound applies under Global without character subfolders.

OLD_DIR_NAME selects a source directory. NEW_DIR_NAME names the destination; blank or TBD falls back to the source name with a trailing _xxx_0 removed. Usable CharacterName values can create character subfolders. file_pattern uses ####### for a seven-digit hexadecimal line identifier. The current consumer does not use file_regex or file_glob.

These are consumer rules. Character, level and stream associations remain research data; rename destinations are not proof of original paths, runtime event mappings or hash algorithms.
